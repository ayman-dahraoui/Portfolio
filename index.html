Stagiaire Data Scientist — Al Barid Bank

Division Data & BI · Projet : Détection d'anomalies sur les indicateurs de performance mensuels
Juil. – Août 2026 (2 mois) · Rabat
Rappel 90.8 % vs 63.4 % ML seul 50 agences · 13 KPI
  • Problématique : absence de contrôle automatisé sur les indicateurs de performance mensuels, exposant les rapports à des erreurs silencieuses non détectées
  • Conception d'un système hybride (règles statistiques + Machine Learning) pour la surveillance des indicateurs de performance commerciale sur 36 mois d'historique
  • Cadrage métier et rédaction du cahier des charges — identification de 6 types d'anomalies (valeur aberrante, pic/chute de volume, incohérence de cumul, stagnation, rupture de tendance)
  • Génération et EDA d'un dataset synthétique de 23 400 lignes respectant le schéma métier fourni
  • Implémentation de 5 règles de détection (z-score, seuils de variation, cohérence de cumul, stagnation, rupture de tendance) avec évaluation individuelle et ajustement itératif des seuils
  • Entraînement d'un Isolation Forest non supervisé + test de robustesse (1 vs 3 variables) pour écarter le risque d'artefact
  • Fusion règles + ML en un système en cascade — rappel de 90.8 % contre 63.4 % pour le Machine Learning seul, avec traçabilité de la détection (Detected_Type)
  • Restitution : dashboard Power BI interactif (filtres période / agence / type) + interface web FastAPI + React
  • Rédaction du rapport de stage complet en LaTeX et des schémas techniques (architecture, pipeline, Gantt)
Stack Pythonscikit-learnIsolation Forest PandasFastAPIReact.js Power BILaTeX
